What you will build

blog-coding-tutorials/c03-attention

A small attention library called attnzoo. One config describes the architecture (MHA, MQA, GQA, MLA, linear, cross). A separate setting picks the kernel that runs it (naive, SDPA, tiled, FlashAttention). A test suite proves the versions agree with each other, with PyTorch and with Hugging Face.

The plan

Almost every speed and memory decision in a modern language model lives inside one small function. What does that function compute, tensor by tensor, and how do we know each faster version is still correct?

We answer by building it. We start with four lines of PyTorch. We add one idea at a time and test each one. By the end the same four lines run behind a config that covers the attention of Llama, DeepSeek and Swin.

The derivations live in the theory posts, so we link them and move on. Here we implement the idea and look at what happens.

The post has twelve parts. Each stands alone, so you can stop after any of them.

Clone the repo once. Every command below runs from its root.

Every number below comes from one Apple M5 laptop with 16 GB of memory, in CPU or MPS mode, running PyTorch 2.15. Several other long jobs were using the same machine at the time. So read absolute timings as rough, and trust the ratios and scaling more. Memory counts and numerical errors do not depend on load.
