Blog posts must follow `docs/blog-writing-guide.md` in the repo (the user asked for it as standing instructions for all upcoming blogs).

Key points: thorough deep literature survey covering the whole field; first-principles build-up with a clear flow; a comparison table along the aspects introduced; evidence-backed Insight/Nuance callouts plus a "Key insights and nuances" section; simple language, short sentences, short paragraphs; never make the reader solve correspondence problems ("respectively", "the former/latter", "and all", "etc."); professional, no hype; plain non-cringe headings; high-quality multi-stage animations plus interactive figures; light paper-theme figures (no sudden dark panels).

**Why:** user feedback across the thesis post and the VLM series request (2026-11-06).
**How to apply:** read the guide before drafting any post or briefing writer agents; related [[feedback-commits]].
