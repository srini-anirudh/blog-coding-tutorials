Plain residual: the first 12 blocks each add v = 0.889 * ||x_0||^2 of squared norm, so ||x_L||^2 ~ ||x_0||^2 (1 + L v).
Log-log slope of (||x_L||^2 - ||x_0||^2) against L: 1.030 (1.0 means linear in L, so ||x_L|| ~ sqrt(L)).
Prediction for L = 96 from those 12 blocks: sqrt(1 + 96 v) = 9.291; measured 9.558.
Branch outputs are near-orthogonal to the stream, so they add in quadrature like a random walk.
Note: the 1/sqrt(2L) rule fixes the total added variance (about v/2) rather than letting it grow with L.

The norm of each group falls far below the C(L,k) ||J||^k count: paths of the same length point in
near-random directions and partly cancel, so each group grows roughly like sqrt(C(L,k)) ||J||^k instead.
The post's binomial weighting C(L,k) ||J||^k gives mean path length L ||J|| / (1 + ||J||) = 2.86;
weighting by squared norms of the measured groups gives 1.57. Either way the
gradient is carried by paths far shorter than L = 10.
