1. Causal linear attention, (B=2, H=4, T=256, d=32), phi = elu + 1, C3's implementations:
   parallel vs recurrent, max |diff| = 8.9e-16
   state per sequence: 33,792 bytes at any length. A KV cache at T = 256: 524,288 bytes,
   and it keeps growing with T.

   independent: random keys, nearly orthogonal. The two state rules are close up to n = 32; past n = d
   the delta rule's overwrites cost more than the additive blur. Both lose to the full cache.
   correlated: keys share a direction (mean cosine about 0.5). The additive state blurs them together;
   the delta rule removes what the state already returns for k before writing, and does better.

3. Updating a memory: write 16 pairs, then write the same 16 keys again with new values.

-----------+---------------------+--------------------
linear     | 0.624               | 0.641

   The additive state returns a blend of old and new; the delta rule returns the new value.
