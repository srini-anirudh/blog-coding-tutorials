Reverse mode stays flat as inputs grow. Forward mode and finite differences grow with the number of inputs.
Forward mode here is vmapped (torch.func.jacfwd), so its n sweeps run as one batched pass.

The post's cost estimate for finite differences, recomputed:
  2 passes x 1e+11 parameters x 2N FLOPs = 4.0e+22 FLOPs per token
  at 1000 TFLOP/s: 4.0e+07 s = 1.27 years per token
  The post says about 1.3 million years. The same inputs give about 1.3 years per token, so the post's
  figure looks a factor of 10^6 too large. The conclusion (finite differences are hopeless) still holds.
  This is arithmetic, not a measurement.
