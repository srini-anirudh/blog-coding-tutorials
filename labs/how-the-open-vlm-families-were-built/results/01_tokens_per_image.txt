How each rule spends tokens on the letter scan (1700 x 2200):
  LLaVA-1.5        LLaVA-1.5: 336 px square, 24 x 24 tokens
  Qwen-VL          Qwen-VL: 448 px square, 1,024 patches read by 256 learned queries
  Gemma 3          Gemma 3: 896 px square, 16 x 16 tokens
  MiniCPM-V 2.5    MiniCPM-V 2.5: about 9 slices + the whole image, 96 each
  Idefics3         Idefics3: 4 x 4 tiles of 364 px + global view, 169 tokens each
  DeepSeek-VL2     DeepSeek-VL2: 3 x 3 tiles + thumbnail
  LLaVA-NeXT       LLaVA-NeXT: 2 x 2 tiles of 336 px + base; 38 x 48 unpadded tokens + 48 newlines
  LLaVA-OneVision  OneVision: 5 x 6 canvas, tile tokens 71 x 92 after unpadding and interpolation
  InternVL 1.5-3   InternVL: 3 x 4 tiles + thumbnail, 256 tokens each
  Pixtral          Pixtral: 50 x 64 patches + 64 row-end tokens
  Qwen2/2.5-VL     Qwen2-VL: resized to 1708 x 2212, 61 x 79 merged tokens
