native: Qwen2-VL smart_resize (sides rounded to multiples of 28), one token per 28 x 28 pixels.
Fig.4 tiles: the post's figure covers the page with 448-px tiles at its own size, +1 thumbnail, 256 tokens each.
InternVL: the grid is chosen by aspect ratio alone (closest to 0.707 is 5 x 7 with max 40, 2 x 3 with max 12),
  and the page is resized to that grid. So the tile count does not grow with dpi: low-dpi pages are upscaled.

Fixed-budget encoder (DeepSeek-OCR native modes): 16-px patches, then 16x token compression.
   512 px ->  64 tokens,  15.6 text tokens per vision token, page shrunk to  43.8 dpi: 10-pt text gets  6.1 px per em
   640 px -> 100 tokens,  10.0 text tokens per vision token, page shrunk to  54.7 dpi: 10-pt text gets  7.6 px per em
  1024 px -> 256 tokens,   3.9 text tokens per vision token, page shrunk to  87.6 dpi: 10-pt text gets 12.2 px per em
  1280 px -> 400 tokens,   2.5 text tokens per vision token, page shrunk to 109.5 dpi: 10-pt text gets 15.2 px per em
